# Single vs. Multi-Agent Heterogeneity in Hypothesis Generation

## Problem Statement

Recent literature indicates that multi-agent debate (MAD) systems often suffer from sycophancy and premature consensus when generating scientific hypotheses. This project investigates whether introducing deliberate persona heterogeneity mitigates inter-agent sycophancy compared to a homogeneous baseline. This serves as the executable experimental study required for the assignment[cite: 2, 10].
